上下文工程 固定任务剥离 微上下文流水线 字段级隔离

问题表现 — 主 Agent 在单一长会话中逐字段处理，每个字段的加工和推理在字段完成后即失去价值，却持续占据上下文，随着上下文膨胀，Agent 对后续字段的处理逐渐脱轨。

解法 — 固定任务剥离：整套字段处理剥离为独立脚本，主 Agent 只发起一次工具调用、接收 tool_result，复杂执行过程不进入主 Agent 上下文；微上下文流水线：脚本以字段为隔离单元，给每个字段开一条五阶段的小流水线并行执行。

下图对比三种上下文形态。条1：单 Agent 长会话逐字段串行；条2：主 Agent 视角 —— 上下文中剥离字段加工的复杂执行过程；条3：字段级微上下文 —— 字段 A 与 字段 B 各自一个独立短会话。
