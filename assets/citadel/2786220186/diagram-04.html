上下文工程 主子 Agent 设计 交付物接力

问题表现 — 单 Agent 在同一会话中跑完五个研发环节，PRD 全文、技术方案、代码 diff、测试日志全部堆积在同一上下文中，早期环节的结论随执行推进滑向中段低权重区。

解法 — 主子 Agent 设计：调度 Agent 只持有任务级全局状态（计划、进度、交付物路径），执行细节由子 Agent 各自独立上下文冷启动承接 —— 关键结论以落盘交付物显式传递，而非会话记忆。

下图对比三种上下文形态。条1：单 Agent 长会话跑全链路；条2：调度 Agent 视角——只见编排调用与交付物路径；条3：子 Agent 视角 —— 以代码开发 Agent 为例，独立短会话冷启动，环节间交付物接力。
