# 面壁计划

*The Wallfacer Plan*

宇宙真正令人恐惧的地方，也许从来不是它的辽阔，而是它的沉默。

无数恒星燃烧了亿万年，却没有任何一个声音告诉你：前方是朋友，还是猎手。在《三体》的宇宙里，信息传播得太慢，技术增长得太快。一次回答尚未抵达，发出回答的文明就可能已经面目全非。猜疑在漫长的等待中延续，而每一个决定，都必须在真相到来之前作出。

面壁者的故事里，还有另一种沉默。

人们看得见他走向哪里，调用什么资源，作出什么决定，却不知道这些动作最终将在何处汇合。一次无法解释的转向，一项迟迟没有结果的工程，在外界看来彼此孤立，在他的头脑中却可能属于同一条尚未显现的线。

一个计划最初的形状，也许只有一个人知道。

---

我们的世界没有智子。使它逐渐透明的东西，出现在每天亮起的屏幕上。

知识被搜索，代码被生成，经验被压缩成教程，方法被封装成 Agent。曾经需要长久摸索才能抵达的地方，正在成为越来越多人的起点。我们获得了更多能力，也更频繁地站在岔路口。

我想学会使用这些智能，也想参与创造它们。但在一次次调用之后，我仍然需要独自回答：接下来，把自己的时间放在哪里？

有些问题可以同时交给许多机器，一个人的几年却只能亲自度过。选择一条路，意味着让另一些可能性渐渐远去。工具可以缩短完成一件事的时间，却不能替我决定，什么值得用一生中有限的几年去完成。

也许真正属于一个人的，是他对未来的内部地图。

哪些变化只是噪声，哪些值得长久注视；什么应该立刻追逐，什么需要耐心等待；什么看似重要，却决定放弃。许多改变轨迹的判断，发生时都很安静。没有人要求你记录，也没有人知道，你曾在那里停留过。

---

于是，我给自己留下了这个地方。

读过的文档，收集的信息，尚未成形的念头，都可以暂时放在这里。有些会在几天后被推翻，有些要经过几年才看得出意义。保存它们的时候，我还不知道区别。

我愿意交流代码、论文和失败，也希望保有一段不急于回应外界的时间。一个想法可以在这里待得久一点，不必刚刚出现，就回答它有什么用、何时会有结果。

在这里，我可以慢慢问自己：

**我究竟相信什么正在发生？**

然后留下当时的回答。连同那些使我相信的理由，那些尚未消除的怀疑。

多年以后，回望一条轨迹时，人总容易产生一种错觉：仿佛每一步都早有安排。可我希望这些记录仍然保留出发时的样子——那时只能看见眼前几步，选择时有过犹豫，也曾认真走向后来放弃的方向。

所谓长期战略，也许并不是提前知道终点，而是在不断变化的世界中，始终保有一套自己的坐标系，并一次又一次修正它。

这里是面壁计划，一个人的私人档案。
