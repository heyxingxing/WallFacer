# 面壁计划

**The Wallfacer Plan**

在不断变化的世界中，保存一份可以被修正的个人坐标。

---

## 一 · 沉默

在《三体》的黑暗森林设定中，遥远的星光无法回答一个近在眼前的问题：对方是否值得信任。

一次询问发出以后，回答尚在途中，提出问题的文明就可能已经改变。距离延缓了理解，技术增长又不断使旧有的判断失效。文明必须根据极其有限的证据，决定下一步行动，并承担无法撤回的后果。

这个设定留下的问题，比星际战争更接近一个普通人的生活：当你无法获得完整的信息，又不能无限期地等待，你如何决定自己的方向？

## 二 · 行动的含义

面壁者拥有一个只有自己知道意义的行动序列。

外界可以记录他的行程、资源和决定，可以逐项解释每个动作，却仍然无法确定它们最终将在何处汇合。同一组行动，在不同的计划中，可能通向完全不同的结果。

一个计划在被写下来之前，就已经开始形成：有些问题获得了更高的优先级，有些机会被放弃，有些暂时无法解释的工作被继续推进。方向先于完整的路线出现。

对一个人来说，这样的行动可能很小。读一篇论文，重做一个实验，追查一次失败，决定在某个问题上再花一个月。当下看起来互不相干的事情，会在长期积累中逐渐显出联系。

## 三 · 透明的世界

回到今天，屏幕上的光来自一台计算机。

知识可以被搜索，代码可以被生成，经验被写进教程，方法被封装成 Agent。我正在学习怎样使用这些工具，也希望参与创造更强的智能。与此同时，一个问题开始变得具体：如果越来越多人能够调用相似的能力，我该把有限的时间用在哪里？

工具可以帮助我列出路线、检验假设、完成实验。但选择研究哪个问题、愿意为它投入多久、在什么证据出现时改变方向，仍然需要我作出判断。

我关心 agentic RL、递归自我改进（RSI）和 harness engineering。这些方向还会变化，对它们的理解也会变化。我希望留下每一次选择时的依据，以便未来能够检查：当时究竟看到了什么，又遗漏了什么。

## 四 · 内部地图

每个人都在用自己的经历绘制一张关于未来的地图。

地图上有已经走过的路，有从别人的报告中抄录的地形，也有大片仅凭推测填入的区域。它们看起来可能同样清晰，可靠程度却相差很远。

因此，这里既保存文档，也保存文档引起的问题；既记录实验结果，也记录实验开始前的预期。一个判断被推翻时，它原来的依据仍然值得保留。只有这样，修正才有迹可循。

哪些变化只是噪声，哪些值得投入几年时间；什么需要立刻尝试，什么可以继续等待；什么看似重要，却决定放弃。这些问题共同决定了地图的形状，也决定了一个人最终走向哪里。

## 五 · 留出空间

在这个项目里，面壁意味着为尚未成熟的判断留出时间。

代码、论文、成果和失败都可以交流。一个想法也需要接受外部证据的检验。但在它能够被清楚表达之前，我希望有一个空间，容纳没有结论的阅读、反复改变的方案，以及暂时看不到用途的探索。

这个私有仓库承担这样的用途。资料在这里归档，思考在这里留下版本，一些问题可以跨过几次热点更替，仍然保持打开。

我会不时回到这里，重新回答同一个问题：**我究竟相信什么正在发生？**

回答之后，还要写下使我相信它的证据，以及可能使我改变判断的条件。

## 六 · 多年以后

多年以后，回望一条已经走过的轨迹，人很容易产生一种错觉，仿佛每一步都早有安排。

这里的记录应当保留另一种面貌：当时能够看到的只有眼前几步，许多选择带着犹豫，有些方向最终被证明是错的。后来的结果，不应抹去行动发生时的未知。

所谓长期战略，也许就是在不断变化的世界中，始终保有一套自己的坐标系，并一次又一次修正它。

面壁计划从保存第一份资料开始。下一步的方向，将由学习、实践和新的证据共同决定。

## 档案

这里保存我提供给本项目的文档、信息与思考，并同步到 GitHub 私有仓库。

| 位置 | 内容 |
| --- | --- |
| `documents/` | 原始文档，尽量保留原文件名、内容与格式 |
| `notes/` | 文字、链接、阅读笔记、问题与判断记录 |
| `assets/` | 图片及相关附件 |

目录按需建立。原始资料与整理稿分开保存；记录已知的来源与日期，区分事实、推断和未知。每次归档通过 Git 留下版本，使后来的自己能够回到当时的信息与判断。
