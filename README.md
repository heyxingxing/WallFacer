# 面壁计划（The Wallfacer Plan）

这是一个个人资料归档项目，用于保存我向此项目提供的文档和信息，并同步到 GitHub 私有仓库。

## 归档方式

- 上传的原始文件放在 `documents/`，尽量保留原文件名和内容。
- 明确要求保存的文字、链接和其他信息放在 `notes/`，使用 Markdown 记录，注明日期和来源（如有）。
- 图片及相关附件放在 `assets/`，保持文档中的引用可用。
- 需要整理或解读时，将整理稿与原始资料分开，保留来源，不把推断写成原文事实。

目录按需创建。每次归档后，以 Git 提交记录变化并推送到私有仓库。

## 仓库

- GitHub： https://github.com/xingxing-dev/the-wallfacer-plan
- 可见性：私有。
