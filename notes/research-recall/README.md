## 怎样使用

从 [继续工作的方法](METHOD.md) 开始：恢复问题 → 找一条证据 → 检查版本变化 → 选择一个最小动作 → 更新判断。新增内容沿用 [回顾模板](TEMPLATE.md)。

- [原项目地址与版本](PROJECTS.md)：原源码通过地址重新访问，不重复存储。
- [来源索引](sources.json)：本地文件位置与本次内容指纹，供追溯而非备份。
- [代码改动索引](code-changes.json)：七个修复的父提交、提交与文件列表，不含代码正文。

## 记录范围

“本地沉淀”包含 AI 协作整理、源码研究和衍生翻译，不表示独立发明全部方法。历史运行结果按原资料范围记录；此次只整理与核对，没有新跑训练或 benchmark。
